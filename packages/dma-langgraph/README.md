# dma-langgraph

`dma-langgraph` provides thin, explicit DMA memory nodes for LangGraph. It
adds context to graph state before your LLM node; your application remains in
control of which facts are saved afterward.

```bash
pip install dma-langgraph 'dma-langgraph[langgraph]'
```

See the repository's `examples/langgraph` directory for a complete graph.
